# Configuración antes de ejecutar

La configuración Firebase personal de `app/google-services.json` no se incluye en esta copia. También se excluyeron las rutas locales del SDK, los registros, las compilaciones y las cachés.

El proyecto puede funcionar en modo local sin ese archivo; para compartir la mochila configura un proyecto propio siguiendo `docs/CONFIGURAR_FIREBASE.md`. Las reglas y sus pruebas están incluidas.

No se encontraron cuentas de servicio, claves privadas ni contraseñas en el código analizado. `google-services.json` es configuración del cliente, no una clave privada de administración, pero se ha omitido para evitar asociar la copia pública a tu backend personal.

Los códigos privados de acceso a mochilas, las fotos y las copias de inventarios reales no deben añadirse a ejemplos, capturas, pruebas ni al historial. No se ha accedido a la base de datos real ni a los móviles.
